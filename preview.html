01

먼저, 검색 범위를 선택하세요

  1. Figma에서 플러그인을 실행하고, 캔버스의 그룹이나 프레임을 선택합니다.
  2. 상단의 검색 기준에서 범위 이름과 하위 텍스트 수를 확인합니다.
  3. 텍스트 · 레이어/그룹 · 유형별 중 원하는 탭에서 작업합니다.
선택 범위가 작업의 시작점입니다.

버튼이 비활성화되어 있다면 검색 범위를 먼저 선택하세요. 검색어나 변경할 내용이 필요한 기능은 해당 입력도 채워야 합니다.

02

텍스트를 찾고 바꾸기

범위 안의 텍스트 한 번에 선택

모든 텍스트 선택을 누르면 검색 범위 안의 텍스트를 모두 선택합니다.

같은 서체·크기·색상의 텍스트 선택

기준으로 사용할 텍스트 하나를 선택하고 스타일 기준에 표시된 서체, 크기와 색상을 확인하세요. 같은 서체 선택, 같은 글자 크기 선택 또는 같은 글자 색상 선택으로 원하는 기준의 텍스트를 찾습니다. 같은 서체·크기·색상 선택은 세 조건이 모두 같은 텍스트만 선택합니다.

검색한 텍스트를 새 내용으로 변경

찾을 텍스트를 입력한 뒤, 전체 내용이 같으면 텍스트 일치 선택, 일부에 포함되면 텍스트 포함 선택을 누릅니다.

예시구매하기→지금 구매하기
  1. 변경할 텍스트에 새 내용을 입력합니다.
  2. 변경 범위를 선택합니다. 선택한 결과만 바꾸려면 ‘선택한 텍스트 레이어만’, 범위 안에서 찾은 내용을 바꾸려면 ‘검색 범위 전체’를 사용합니다.
  3. 텍스트 내용 변경을 눌러 적용합니다.
03

레이어 이름을 정리하기

플러그인의 레이어/그룹 탭에서 시작하세요.

이름으로 찾기

레이어 이름 찾기에 검색어를 입력하고 이름 일치 선택 또는 이름 포함 선택을 누릅니다. 동일한 이름 선택은 선택된 레이어 안에서 같은 이름의 레이어를 탐색합니다.

검색 결과에서 한 단계 더 탐색

이름으로 선택한 뒤 유형별 선택 (한 단계씩)의 오토레이아웃·프레임·그룹·컴포넌트·텍스트 버튼을 누릅니다. 현재 선택한 레이어의 바로 아래 단계를 탐색하므로, 버튼을 다시 누르며 하위 구조로 이동할 수 있습니다.

새 이름 적용

레이어 이름 바꾸기에 새 이름을 입력하고, 선택한 레이어만 또는 검색 범위 전체를 확인한 뒤 레이어 이름 변경을 누릅니다.

이름 정리 예시Card→Product Card
04

유형으로 선택하고 구조 바꾸기

플러그인의 유형별 탭에서 구조를 다룰 수 있습니다.

유형별 레이어 선택

오토레이아웃·프레임·그룹·컴포넌트 중 원하는 버튼을 누르면 선택한 레이어의 바로 아래 단계에서 해당 유형을 찾습니다.

구조 유형 변환

선택 유형 찾기와 바꿀 유형 선택을 설정하고 구조 유형 변경을 누릅니다. 오토레이아웃으로 바꿀 때는 세로·가로 방향도 지정하세요.

유형 선별 그룹화

선택한 각 레이어를 각각 새 컨테이너로 묶습니다. 오토레이아웃은 버튼을 누른 뒤 방향을 선택하고 오토레이아웃으로 그룹화로 적용합니다.

구조 변환 전 확인하세요.

프레임과 그룹 변환은 회전된 구조나 오토레이아웃 부모 안에서는 지원되지 않습니다. 그룹으로 변환하면 프레임의 배경·테두리·클리핑이 유지되지 않습니다.

자주 묻는 질문

이 페이지에서 Figma 파일도 바뀌나요?

이 페이지는 실제 ui.html을 불러와 조작하는 브라우저 체험입니다. 선택 상태는 예시이며 검색·변경·그룹화는 Figma 문서에 적용되지 않습니다. 실제 작업은 Figma 안에서 플러그인을 실행해 주세요.

같은 서체·크기·색상 선택 버튼은 언제 사용할 수 있나요?

검색 범위와 기준 텍스트 정보가 있어야 합니다. 서체가 혼합된 텍스트, 크기가 혼합된 텍스트 또는 단색 색상 정보가 없는 텍스트는 해당 기준의 버튼이 비활성화될 수 있습니다. 여기서는 체험 상태를 ‘텍스트 기준 선택’으로 바꾸어 확인하세요.

변경 버튼을 누른 뒤 입력이 사라졌어요.

Figma에서 변경 작업이 완료되면 입력이 초기화됩니다. 이 페이지에서는 체험 설정의 ‘변경 요청 후 입력 초기화’를 켜면 같은 입력 초기화를 확인할 수 있습니다.
