텍스트 전부 선택

텍스트 지정 선택

스타일 기준 텍스트를 선택하면 크기와 색상을 표시합니다.

텍스트 검색 선택·변경

텍스트를 찾거나 바꿉니다.

레이어/그룹 전체 선택

선택된 레이어 안에서 같은 이름의 레이어를 탐색합니다.

레이어/그룹 검색 선택·변경

이름을 입력하고 선택/변경합니다.

→

유형별 선택 (한 단계씩)

검색 결과를 선택한 뒤 이름을 바꾸거나 아래 유형별 버튼으로 탐색합니다.

유형별 레이어 선택

선택한 레이어의 바로 아래 단계에서 유형별 레이어를 탐색합니다.

구조 유형 변환

선택 범위에서 그룹·프레임·오토레이아웃 구조를 다른 유형으로 변경합니다.

→

선택 범위에서 지정한 구조만 변경합니다. 프레임과 그룹 변환은 회전된 구조나 오토레이아웃 부모 안에서는 지원되지 않습니다. 그룹 변환 시 프레임 배경·테두리·클리핑은 유지되지 않습니다.

유형 선별 그룹화

선택한 각 레이어를 선택한 구조 유형의 컨테이너로 각각 묶습니다.

기능 사용 도움말

시작하기

  • Figma에서 그룹이나 프레임을 선택하고 상단의 검색 기준을 확인하세요.

텍스트 검색

  • 모든 텍스트 선택: 검색 범위 안의 텍스트를 모두 선택합니다.
  • 스타일 선택: 텍스트 하나를 기준으로 같은 서체·크기·색상을 찾습니다. ‘같은 서체·크기·색상 선택’은 세 조건이 모두 같은 텍스트만 선택합니다.
  • 검색·변경: 찾을 내용을 입력하고 일치·포함 선택을 누릅니다. 새 내용과 변경 범위(선택한 텍스트 레이어만 / 검색 범위 전체)를 확인한 뒤 ‘텍스트 내용 변경’을 실행하세요.

레이어/그룹명 검색

  • 동일한 이름 선택: 선택된 레이어 안에서 같은 이름의 레이어를 찾습니다.
  • 이름 검색·탐색: 찾을 이름을 입력하고 일치·포함 선택을 누릅니다. 유형별 버튼을 누르면 현재 선택의 바로 아래 단계에서 탐색합니다.
  • 이름 변경: 새 이름과 변경 범위(선택한 레이어만 / 검색 범위 전체)를 확인한 뒤 ‘레이어 이름 변경’을 실행하세요.

유형별 검색

  • 유형별 선택: 현재 선택의 바로 아래 단계에서 오토레이아웃·프레임·그룹·컴포넌트를 찾습니다.
  • 구조 유형 변환: 찾을 유형과 바꿀 유형을 지정해 그룹·프레임·오토레이아웃을 변환합니다. 오토레이아웃은 방향도 선택하세요.
  • 유형 선별 그룹화: 선택한 각 레이어를 지정한 유형의 새 컨테이너로 각각 묶습니다.
  • 그룹 변환 시 배경·테두리·클리핑은 유지되지 않습니다. 프레임·그룹 변환은 회전된 구조나 오토레이아웃 부모 안에서 제한됩니다.

키보드

  • 검색 입력에서 Enter: 포함 검색 및 선택
  • 변경 입력에서 Enter: 변경 실행
  • 탭에서 ←/→로 이동, Home/End로 처음·끝 탭 선택
  • Tab/Shift+Tab으로 이동, Esc로 안내 닫기
